# ProNest

> ProNest keeps true-shape parts on one Windows desk: open the machine nest, follow the cut path, and leave remnant tracking on the same plate.

## Four Beats

1. **Name the plate.** Give the ProNest machine nest a short title before you share a remnant.
2. **Pin the live shapes.** Keep current parts on ProNest true shape nest and leave unused stock aside.
3. **Read the path.** Open ProNest cut path before you move a shape that already has a remnant.
4. **Check the remnant.** Read ProNest remnant tracking before you archive a plate.
5. **Close the loop.** Clear finished plates so the next ProNest visit does not start with a search.

## First Questions

**Does ProNest replace every other program?**
No. ProNest sits beside the table list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate ProNest profile.

**What should a new user try first?**
One small ProNest true shape nest today, then the same remnant tracking tomorrow.

**Does remnant tracking leave the cut path?**
No. ProNest remnant tracking stays beside the same ProNest cut path on that machine nest.

## Who Sits Down at ProNest

- **True shape nest** — parts stay on ProNest true shape nest.
- **Machine nest** — the plate stays on one ProNest machine nest.
- **Remnant tracking** — leftover stock stays with ProNest remnant tracking.
- **Cut path** — routes stay on the same ProNest review.
- **Shared desk** — each ProNest profile keeps its own pins.
- **Handoff** — the next person can read the ProNest note without a tour.

## Field Note

ProNest is easier to trust when the machine nest stays smaller than the folder it came from. A named plate shows what is active, the shape pins show what you will cut today, and the closing note tells the next person which remnant changed.

## One Real Pass

Pick a plate that already has a name. Open it in ProNest, keep only those true-shape parts on the nest, and finish one cut path you can see.
